## Deploy to GitHub Pages (5 minutes)

1. **Create a new GitHub repo** named exactly: `YOUR-USERNAME.github.io`  
   *(e.g. `j-m.github.io`)*

2. **Upload `index.html`** to the root of that repo

3. Go to repo **Settings → Pages → Source: Deploy from branch → main / root**

4. Your site will be live at `https://YOUR-USERNAME.github.io` within a minute or two

## Customization

All content is in a single `index.html` file. To update:

- **Metrics** — find the `.metrics-grid` section
- **Colors** — edit CSS variables at the top of the `<style>` block
- **Fonts** — swap Google Fonts import links
